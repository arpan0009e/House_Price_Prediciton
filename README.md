# 🏠 House Price Prediction using Multiple Linear Regression

## 📌 Project Overview

This project focuses on predicting house prices using **Multiple Linear Regression**, a supervised machine learning algorithm. The model analyzes multiple housing features and estimates the expected price of a house based on those inputs.

The objective of this project is to understand the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), model training, evaluation, and prediction.

## 📊 Machine Learning Workflow

### 1. Data Collection

The housing dataset is loaded using Pandas and inspected for missing values and inconsistencies.

### 2. Data Preprocessing

* Handling null values
* Encoding categorical features (if applicable)
* Feature selection
* Splitting data into training and testing sets

### 3. Model Training

A **Multiple Linear Regression** model is trained using Scikit-Learn.

### 4. Model Evaluation

The model performance is evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)

### 5. Visualization

Graphs are created to compare:

* Actual Prices vs Predicted Prices
* Best Fit Line
* Feature Relationships

## 🧠 Multiple Linear Regression Formula

y=\beta_0+\beta_1x_1+\beta_2x_2+\cdots+\beta_nx_n

Where:

* **y** = Predicted House Price
* **β₀** = Intercept
* **β₁...βₙ** = Coefficients
* **x₁...xₙ** = Independent Features
